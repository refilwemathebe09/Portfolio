## Getting Started

To run this project locally:

1. Clone the repository:

```bash
git clone https://github.com/refilwemathebe09/Portfolio.git
```

2. Navigate to the project folder:

```bash
cd Portfolio
```

3. Open the project in a browser:

- You can open `index.html` directly in a browser, or
- Run a local web server if preferred

Example with Python:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This portfolio is deployed on Netlify.

### Netlify deployment steps

1. Push the project to a GitHub repository.
2. Sign in to Netlify.
3. Click "Add new project".
4. Select the repository.
5. Use the default build settings for a static site.
6. Deploy the site.

The live site is available here:

https://refilwemathebe.netlify.app/
